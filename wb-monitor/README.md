# WB Monitor — сайт мониторинга товаров Wildberries

Добавление ссылок или артикулов WB, таблица цен, доступных остатков (если опубликованы), сроков доставки (если опубликованы), автообновление с интервалами 30/60/120/300 секунд, история последней проверки, экспорт CSV. Список товаров хранится в localStorage браузера.

## Развертывание
1. Распакуйте проект.
2. Импортируйте папку в GitHub (или загрузите в свой проект Vercel).
3. Создайте проект на [vercel.com](https://vercel.com), выберите репозиторий, framework = Other, разверните.
4. API будет доступен по `/api/product?id=123456789&dest=-1257786&currency=kzt`.

Для локального запуска: `npx vercel dev` (потребуется Vercel CLI). `npm test` — тесты API.

## Важные ограничения
- Это best-effort чтение публичных ответов Wildberries, **не официальный покупательский API**. Wildberries может заблокировать `card.wb.ru` для Vercel или изменить схему без предупреждения. Если источник не отвечает, в таблице будет ошибка, а не выдуманная цена.
- Цена зависит от валюты/региона, скидок аккаунта и WB Клуба. API не воспроизводит персональную цену покупателя.
- Точное число штук и дни доставки **не гарантируются** для сторонних товаров: приложение их показывает только если источник явно вернул данные. Большинство карточек не предоставляют `deliveryDays`.
- «Реальное время» здесь означает опрос с заданным интервалом при открытой вкладке, а не непрерывную push-синхронизацию и не фоновую работу 24/7.
- Код региона `dest` — внутренний код WB; значение по умолчанию требует проверки под вашу зону доставки.
- Для надежного коммерческого мониторинга нужен разрешенный поставщик данных с API (и отдельный backend для запуска по расписанию).
