# Marketplace Manager

Внутренняя система управления магазинами на маркетплейсах. Первый этап — Kaspi, позже Flip и Teez.

## MVP

- аналитика продаж: день / неделя / месяц / год;
- выручка, себестоимость, доставка, комиссия, налог, чистая прибыль;
- список и статусы заказов;
- агрегация товаров для поставщиков (Алматы / Курдай);
- сборка заказов сканером штрихкодов;
- карточка товара при сканировании: название, количество, SKU, изображение;
- безопасное подключение Kaspi API через переменные окружения.

## Стек

Next.js, TypeScript, PostgreSQL, Prisma.

## Запуск

```bash
cp .env.example .env
npm install
npx prisma generate
npm run dev
```

API-ключ Kaspi хранить только в `.env` или секретах хостинга. Не коммитить ключ в GitHub.
