# Marketplace Manager

Внутренняя система управления магазинами на маркетплейсах. Первый этап — Kaspi, позже Flip и Teez.

## Уже работает в MVP

- интерактивная аналитика: день / неделя / месяц / год;
- расчёт выручки, себестоимости, доставки, комиссии, налога и чистой прибыли;
- поиск и фильтрация заказов;
- автоматическая агрегация потребности по поставщикам WB Алматы / Курдай;
- расчёт дефицита относительно остатка на складе;
- сборка заказов сканером штрихкодов с контролем количества;
- карточка товара при сканировании: название, SKU, поставщик и количество;
- экран статуса подключения Kaspi API и PostgreSQL;
- безопасное подключение Kaspi API через переменные окружения.

## Стек

Next.js, TypeScript, PostgreSQL, Prisma, Vercel.

## Запуск

```bash
cp .env.example .env
npm install
npx prisma generate
npm run dev
```

API-ключ Kaspi хранить только в `.env` или секретах хостинга. Не коммитить ключ в GitHub.

## Переменные окружения

```env
DATABASE_URL="postgresql://..."
KASPI_API_KEY="..."
KASPI_API_BASE_URL="https://kaspi.kz/shop/api/v2"
```

Демо-данные находятся в `lib/mock-data.ts`. После подключения Kaspi они будут заменены синхронизацией реальных заказов в PostgreSQL.
