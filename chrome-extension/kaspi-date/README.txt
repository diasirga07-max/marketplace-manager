GRANTS BOOK — Kaspi даты

Установка в Google Chrome на Mac/Windows:
1. Распакуйте ZIP в постоянную папку.
2. Откройте: chrome://extensions
3. Включите «Режим разработчика» (Developer mode).
4. Нажмите «Загрузить распакованное расширение» (Load unpacked).
5. Выберите папку grants-book-kaspi-date-extension.
6. Откройте кабинет продавца Kaspi и войдите в аккаунт.
7. Откройте GRANTS BOOK → «Даты принятия».
8. Выберите дату и нажмите «Сохранить дату».

Расширение автоматически использует авторизованную вкладку Kaspi. Если нужная дата недоступна в самом Kaspi, GRANTS BOOK покажет ошибку и список доступных дат, если их удалось прочитать.
